# Design

## Colors
- Primary: #2E86AB (blue)
- Danger: #D62828 (red — for fraud)
- Safe: #06A77D (green — for normal)
- Background: #F5F5F5
- Text: #1A1A1A

## Typography
- System default
- Headings: bold
- Body: regular

## Charts
- Confusion matrix: heatmap
- ROC curve: line plot
- Feature importance: horizontal bar
- Class distribution: bar chart

## Style
- Clean, minimal
- No clutter
- Every chart has a title and axis labels
